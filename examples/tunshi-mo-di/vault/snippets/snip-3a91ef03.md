# 桥段：七寸断

## 原文（第 5 章 28-43 段，约 380 字）

> 林烬咬破舌尖。
>
> 舌尖渗出一点血。林烬把舌尖那点血吐到掌心。他没擦——他用左手食指——那根薄茧的——蘸了一下。
>
> 他的另一只手——左手——伸进衣襟内侧，按到玉简上。
>
> 血——直接接触玉简。
>
> 太阳穴烫。
>
> > **赤焰拳**
> >
> > **原理**：以丹田火属性灵力顺左手腕筋脉环行至右拳，借助"火行三转"将外放灵力凝成短距离爆发。
> >
> > **缺陷**：火行三转在左手腕处必须经过一寸三分的"七寸"位——即左手腕骨突处那条旧筋。此处一旦被外物穿透或被"芸气"截断，火行三转直接断回丹田，回火灼伤施术者。
>
> 林烬收回手。
>
> 赵天霄已经冲到他三步内。
>
> 林烬的视线只停在一个地方。——赵天霄左手腕。
>
> 林烬侧身。不是大幅度的躲，是半步的让。
>
> 赤焰拳从他右肩上方擦过。火星溅在林烬右脸上，留下一点烫红。
>
> 林烬的左袖里——铁针出鞘。
>
> 一击穿入。

## 用法

- **适用**：高境界差距下的智斗反杀；解析流 / 系统流爽点
- **核心范式**："靠分析赢，不靠碾压赢"
- **链式合成**：(a) 前章铺设的"功法弱点信息" + (b) 主动消耗金手指获得"七寸位置" + (c) 一件不起眼的工具（铁针 / 灵草 / 灵符）= 反杀
- **不要用在**：纯肉搏 / 主角已碾压境界差的对决（违和）

## 改造方向

- 把"赤焰拳"换成你书里的招式名
- 把"七寸"换成你书里的弱点表达（穴位 / 阵眼 / 节气 / 灵核）
- 主动消耗的代价（精神力 / 灵气 / 寿命 / 记忆）按你书的金手指调整

> 短句快剪节奏保留 → **完全保留**

## 关键写法要点

1. **解析过程必须有具体代价**：林烬"咬破舌尖"+"渗血触玉简" 是 cheat-system "需要伤口血"的执行。
2. **三层文字独占段落**：让读者跟着主角一起"看到"金手指的输出。
3. **从解析到出招的过渡是"半步"**：不是大幅度躲闪，是侧身让出一个角度。
4. **章末必须有反作用力**：玉简持续发烫、主角喘气、右脸烫红——爽点之后必须有疲倦。
