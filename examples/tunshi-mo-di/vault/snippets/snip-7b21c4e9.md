# 桥段：被罚跪 · 首屏 200 字

## 原文（第 1 章前 200 字）

> 林烬第三次跪下时，膝盖底下那块青石已经磨得温热。
>
> 赵天霄的影子横在他面前，鞋尖踩着他的左手背，慢一拍，又加一分力。
>
> "师弟。"
>
> 赵天霄说话总要先舔一下唇。"听说你这个月只领了七两银子？"
>
> 林烬没抬头。他在数青石上的纹路。第一道，第二道，第三道。数到第七道，他就能让自己听不见对方说话。
>
> 演武场上的风从东南往西北吹，带了一点松香。是后山清理松针的烟。林烬记得这条山道。三百二十二步，他走了三年。

## 用法

- **适用**：网文小说前 200 字开场（起点 / 番茄 / 晋江签约关键）
- **核心范式**：
  1. **冲突进行时**：第一句直接"第三次跪下"——动作已经在发生，不是"曾经发生"
  2. **反派标志性动作**：赵天霄"先舔唇"是 character.md 字段 5#1，前 200 字就立反派人格
  3. **主角不规则小动作**："数青石纹路"是主角抑制痛苦的方式，比内心戏更可视化
  4. **环境锚点**：松香 + 东南风 + "三百二十二步"——五感 + 时间空间锚点合一
  5. **不直接揭穿越**：纸藏胸口的伏笔暗示，但不解释
- **不要用在**：慢热铺垫书 / 言情书的开场（节奏不符）

## 改造方向

- "第三次跪下" → 改为你书的具体冲突起点（"第三次被夺剑"/"第三次走到这条路"等）
- "数青石纹路" → 改为主角的标志性抑制动作（数珠 / 转笔 / 摸耳坠）
- 反派"先舔唇" → 改为你反派的标志性小动作（咂嘴 / 摸耳 / 眯眼）
- 环境锚点保留松香或换一个具体气味（艾草 / 桂花 / 雨后）

## 标签

首屏, 开场, 被罚跪, 数砖块, 压抑, 起点首屏, 冲突进行时

## 关键写法要点

1. **第一句必须是动作**：不要"暮春的清晨..."（环境堆砌开场是 anti-pattern）
2. **不许自我介绍**：直到第二段才出现"林烬"全名，让读者跟着场景认识他
3. **七秒一个钩子**：200 字内出现至少 3 个钩子（残卷 / 穿越 / 反派背后的力量）
4. **不许立 flag**：主角不能在前 200 字想"踏破苍穹"之类（违反性格内核）

## 复用建议

- 这个开场结构在男频网文非常普适
- 推荐放到新书第 1 章作为骨架，再按你书的人物 / 设定填充
