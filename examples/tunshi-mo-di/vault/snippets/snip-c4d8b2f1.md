# 桥段：扫地的师太（试探）

## 原文（第 3 章 12-26 段，约 320 字）

> 师太走到他三步外。她停了。
>
> "小子，"她说，"扫得真齐。"
>
> 林烬慢半拍，"师太。"
>
> 师太的青竹杖在他扫帚扫过的地上点了一下。点了第二下。第三下，杖头转了一个角度。
>
> ——咔。林烬手里的扫帚柄从中间断了。
>
> ...
>
> 走到一半，她忽然问：
>
> "外门弟子，能领月例几两？"
>
> 林烬慢半拍。"七两。"
>
> 师太"嗯"。
>
> 走了二十步。
>
> "你左眉的疤，多久了？"
>
> 林烬这次没立刻回答。走了三步，他才说："一个月。"
>
> 师太"嗯"。她又走。
>
> 走到杂物库房门外，她停下。但没去开门。她转身，把竹杖往身侧靠。
>
> "小子。"她说。"你信不信，宗门里有'清扫组'之外的清扫组？"

## 用法

- **适用**：师徒第一次正式接触；隐藏强者评估弟子；身份差距下的试探戏
- **核心范式**：用一个"物件证明"+ "三句问"的格式
  - 物件证明：让弟子看到强者的真实层次（断扫帚的整齐度）
  - 三句问：前两句是"看你记不记得 / 认不认人"，第三句才是真问题
  - 弟子回答前两句，对第三句保持沉默 = 通过
- **不要用在**：师徒已经熟悉的对话（违和）

## 改造方向

- "断扫帚" → 改为你书的具体动作（碎茶杯 / 折剑鞘 / 弯灯架）
- "三句问"模板可改：「[功能问 1] / [认人问] / [核心问]」三段式
- "凉茶"细节可换：让陌生强者用一个不起眼的招待动作做收尾

## 标签

师徒, 试探, 对话, 断扫帚, 三句问, 智斗, 评估戏

## 关键写法要点

1. **节奏控制**：师太"每三句一停"是标志性细节（character.md 字段 5#3）
2. **关键问题不答 = 通过**：弟子的"沉默"比"回答"更能展示主体性
3. **强者不直接揭身份**：师太说"话没说完别走"是邀请，不是命令
4. **散场动作要克制**：师太走开时反而是弟子鞠躬退出——身份倒置感
