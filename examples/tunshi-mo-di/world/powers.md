# 力量等级体系：末法纪元修真体系

## 体系骨架

基底：**经典仙侠简化版**（炼气 → 筑基 → 金丹 → 元婴 → 化神）。
当代实际只有约 70% 修士能进炼气，化神级是传说人物。

### 炼气

- **阶段细分**：一层至九层
- **核心特征**：灵气吸纳，肉身强化，可发挥简单灵术
- **突破依据**：灵气池满 + 顿悟 + 突破丹（青云外门弟子常需千日苦修）
- **平均年限**：3-5 年（当代）
- **寿命增益**：+30 年
- **大众占比**：80% 修士

### 筑基

- **阶段细分**：初期 / 中期 / 后期 / 圆满
- **核心特征**：筑灵气之基，可凝聚法力，体内有"气海"，可御物
- **突破依据**：筑基丹 + 渡气海凝结劫
- **平均年限**：10-20 年
- **寿命增益**：+80 年
- **大众占比**：15% 修士

### 金丹

- **阶段细分**：初期 / 中期 / 后期 / 圆满 / 大圆满（隐藏）
- **核心特征**：法力凝丹，可御剑万里，开始真正的"修士"地位
- **突破依据**：感应天劫 + 金丹真意
- **平均年限**：50-100 年
- **寿命增益**：+200 年
- **大众占比**：4% 修士

### 元婴

- **阶段细分**：初期 / 中期 / 后期 / 圆满
- **核心特征**：神识凝婴，可短距瞬移、夺舍重生
- **突破依据**：渡九级天劫
- **平均年限**：200+ 年
- **寿命增益**：+500 年
- **大众占比**：< 1% 修士（当代极稀少）

### 化神

- **阶段细分**：初期 / 中期 / 后期 / 圆满
- **核心特征**：魂体合一，碎虚而行，能见过去未来一隅
- **突破依据**：直面"末法本源"试炼
- **平均年限**：500+ 年
- **寿命增益**：+1500 年
- **大众占比**：< 0.001%（当代是传说级别）
