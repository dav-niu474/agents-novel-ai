# 《吞天魔帝》开书蓝图

## 1. 一句话定盘

末法时代穿越者，靠一本残卷解析天地间所有功法，从废柴一步步成为吞天魔帝；最终残卷消失，主角靠自己重启灵气纪元。

## 2. 题材定位

- **主题材**：玄幻
- **副题材**：末法 / 解析流
- **平台**：起点（首选）/ 番茄（同步）
- **受众**：male-young-adult
- **标签**：末法, 穿越, 解析流, 热血, 升级, 智斗

## 3. 主角一句话画像

现代研究生穿越成宗门最末等弟子林烬，自卑、被欺，但有耐心和分析力。最深的渴望是"被看见"，最深的牵挂是穿越前的世界。

## 4. 金手指一句话

《天工残卷》：可解析任何**亲自接触过**的功法 / 法宝 / 灵植 / 气息，输出"原理 + 缺陷 + 优化方向"三层文字；但需要消耗精神力，过度使用会反噬，且会随主角境界分四阶解锁。

## 5. 卖点 / 钩子（前 30 章承诺）

- **第 1 章**：被欺凌的废柴林烬，意外捡到玉简，识出"天工"二字，对路边野草发动第一次解析。
- **第 5 章前**：解析出师兄赵天霄功法的漏洞，反杀挑事者，第一次让宗门外门震动。
- **第 15 章前**：识破宗门长老之间的阴谋，绝境翻盘，引玉清师太半结盟。
- **第 30 章前**：踏入宗门核心区，被长老盯上；残卷因为一次过载使用露出第二段封印。

## 6. 反 AI 味要求

### 高频禁用词（每章 ≤ 2 次）

> 缓缓 / 竟然 / 不可思议 / 震撼 / 那是一种 / 在他看来 / 顿时 / 仿佛 / 一时之间 / 就在这时

### 禁用句式（0 次 / 章）

- ❌ "他眉头一皱，发现事情并不简单"
- ❌ "X 是一种难以言喻的感觉"
- ❌ "时间仿佛凝固了"
- ❌ "心中泛起一阵涟漪"
- ❌ 4 字成语连用 ≥ 3
- ❌ ≥ 3 个形容词列举（"高大、英俊、冷峻、神秘的男人"）

### 必备元素（每章至少 1 项）

- 五感锚点（味道 / 触感 / 听觉 / 嗅觉）
- 不规则的小动作（反映角色性格 / 情绪）
- 具体物件（不是"宝剑"而是"剑柄缠了三圈牛皮的青锋"）
- 时间空间锚点（"申时三刻 / 三步外 / 第二声鸡叫前"）

## 7. 文风指纹

- **参考作者 / 文本**：无（使用通用网文风 + 内置反 AI 词表）
- **风格指纹文件**：—（v1.1 实战暂不启用）

## 8. 排除项

- **不写**：种马 / 龙傲天到底 / 纯打脸爽文 / 重要角色突然黑化无铺垫 / 恶趣味
- **写**：废柴翻身 / 智斗多于硬刚 / 师徒情线 / 失落文明 / 代价与选择

## 9. 章字数 / 节奏

- **章字数**：3500（软范围 ±15%：2975 - 4025）
- **对话占比目标**：30-45%（动作 / 独处章可低至 20%）
- **段落节奏**：手机阅读，2-4 句一段，单段 ≤ 120 字，单句 ≤ 40 字

## 10. 长期意图

- **计划**：约 15 卷 / 800 章
- **整体节奏**：
  - 卷 1-2（第 1-100 章）：觉醒 - 立足宗门
  - 卷 3-4（第 101-200 章）：离巢 - 看到末法世界全貌
  - 卷 5-7（第 201-400 章）：真相边缘 - 触碰末法成因
  - 卷 8-10（第 401-600 章）：决断 - 与上古失败者建联
  - 卷 11-15（第 601-end 章）：吞天 - 重启灵气纪元
- **结局倾向**：开放偏圆满。残卷在第 700+ 章左右"任务完成"消失，主角必须靠自己活下去，并最终重启灵气纪元。
