# 反 AI 味词表与句式（中文网文）

> 这份词表 / 句式收录的是 LLM 高频但读者疲劳的写法。
> chapter-writer 写章节时引用，quality-auditor 审稿时校验。
> v1.0 收录核心约束，v1.1+ 会按题材细分。

---

## 1. 高频禁用词（每章 ≤ 2 次）

### 一类：过度使用的副词 / 拟声

```
缓缓、慢慢、悠悠、淡淡、轻轻、深深、静静
顿时、突然、忽然、骤然、霎时、瞬间
竟然、居然、竟、然、终于、毕竟、显然、果然
仿佛、好像、似乎、恍若、宛如
```

**为什么**：LLM 写中文喜欢用副词修饰动作，但起点 / 番茄读者偏好"动作直接发生"。"缓缓抬手"不如"半秒后才抬手"。

### 二类：万能感叹

```
不可思议、难以置信、令人震撼、目瞪口呆、瞠目结舌、骇然、惊愕、惊骇
匪夷所思、不寒而栗、毛骨悚然、不可名状
```

**为什么**：抽象情绪词代替具体反应。"难以置信"不如"他张了张嘴，没出声"。

### 三类：陈词滥调的过渡

```
那是一种、在他看来、与其说、不仅仅、不仅、而是、也好、不如说
一时之间、一时间、片刻之后、刹那间、霎时间
就在这时、就在此刻、说时迟那时快
```

**为什么**：LLM 用这些做段落连接，读起来很"作文"。

### 四类：现代汉语 / 网络用语（古风 / 仙侠书禁）

```
打卡、Get、安排、官宣、躺平、内卷、破防、yyds
（这些在玄幻 / 仙侠 / 历史 / 武侠书里用是穿模）
```

### 五类：英文翻译腔

```
事实证明、被某种情绪占据、如果...就...、当且仅当
"as if-"、"as though-" 直译过来的句式
```

## 2. 禁用句式

### 万能侦探腔

- ❌ "他眉头一皱，发现事情并不简单"
- ❌ "他的目光中闪过一丝深意"
- ❌ "他的嘴角勾起一抹耐人寻味的弧度"

### 抽象情绪堆砌

- ❌ "X 是一种难以言喻的感觉"
- ❌ "心中泛起一阵涟漪"
- ❌ "心头猛地一震"
- ❌ "脑海中翻涌着无数念头"

### 时空 / 氛围套话

- ❌ "时间仿佛凝固了"
- ❌ "空气中弥漫着一种诡异的气息"
- ❌ "整个世界仿佛只剩下他们两个人"
- ❌ "夜色如墨"（看场景，玄幻能用，但不要每章用）

### 形容词列举

- ❌ "那个高大、英俊、冷峻、神秘的男人"
- ❌ "她有着一双黑亮、灵动、好奇的大眼睛"

> 网文不是描写文学。3 个以上形容词列举默认拒绝。

### 4 字成语堆砌

- ❌ "他的功法绝伦超群、举世无双、独步天下"
- ❌ 同一段连续出现 ≥ 3 个 4 字成语

### 心理独白炸裂

- ❌ 整段（≥ 100 字）都是"他想 / 他觉得 / 他知道"

> 心理独白要被动作 / 对话 / 环境打断，不能一镜到底。

### AI 高频开场

- ❌ "X 月 X 日，宜：开新书"
- ❌ "在一个名为 X 的世界里 ..."（设定堆砌开场）
- ❌ "他叫林烬"（自我介绍开场）
- ❌ "天空是蔚蓝的"（环境堆砌开场）

## 3. 必备元素（每章至少 1 项）

### 五感锚点

不能只用视觉。每章必须有至少 1 个非视觉感官细节：

- **听觉**：远处传来的市声 / 屋檐滴水的节奏 / 别人对话片段
- **嗅觉**：药味 / 汗味 / 旧木 / 雨后土腥
- **触觉**：粗布扎手 / 石头温度 / 衣摆扫过腿
- **味觉**：苦茶 / 灰尘 / 血腥（打斗时）
- **空间感**：脚下台阶数 / 视线高低差 / 风从哪边来

### 不规则的小动作

LLM 喜欢写"标准动作"（举杯、拱手、微笑），读者疲劳。每章至少 1 个**不规则的小动作**：

- 不自觉摸某个物件（标志性细节，引用 character.md 字段 5）
- 中途停下做无关动作（喝水 / 揉眼 / 拨头发）
- 反应延迟（被叫名字 0.5 秒后才转头）
- 错误反应（紧张时突然笑了一下）

### 具体物件

不用类指词。用具体描述：

- ❌ "宝剑" → ✅ "剑柄缠了三圈牛皮的青锋"
- ❌ "酒" → ✅ "去年存的桂花酿，瓶口结了糖晶"
- ❌ "古书" → ✅ "封面被翻出油渍的《杂兵正骨术》"

> 这种"具体物件"不需要每个名词都做，但每章至少 1 处。

### 时间 / 空间锚点

具体到能想象。

- ❌ "过了一会" → ✅ "申时三刻 / 一炷香后 / 第二声鸡叫前"
- ❌ "在远处" → ✅ "隔着三个石阶 / 隔着半条街 / 走十步就到"

## 4. 对话规则

### 对话占比

- 默认 30-45%
- 男频玄幻 / 都市可到 50%
- 女频言情可到 60%
- 慢热 / 内心戏章节可低至 15%（章纲第 7 字段允许时）

### 对话节奏

- 长对白连续不超过 5 轮
- 中间插入：小动作 / 心理 / 环境 / 第三方反应
- 不要 "他说 / 她说" 全用 "说"——交替使用：道、笑、嗤、应、呢喃、压低声、几乎是吼

### 对话标点

- 一行一句对话（移动端阅读友好）
- 长引号（"……"）少用
- 省略号（……）每段最多 1 次

### 对话 ≠ 信息倾倒

- ❌ 角色用对话向另一个角色解释 200 字世界观
- ✅ 信息分多次给，配合角色动作 / 反应

---

## 5. 段落节奏

### 长度

- 每段 2-4 句
- 单段最多 120 字
- 长段必须立刻接短段（节奏对比）

### 结构

- 一段说一件事
- 时间跳跃要换段
- 视角切换要换段

### 单句长度

- 平均 < 25 字
- 单句最长 40 字
- 偶尔出现 1-2 字 / 一句的"超短句"做强调（"风停了。" "他没说话。"）

## 6. 题材专属约束

### 玄幻 / 仙侠

额外禁用：
- "气运 / 福缘"过度使用
- "天道 / 大势"开场
- 称号字数过多（"南海七剑无敌至尊星辰使者"）

### 都市 / 异能

额外禁用：
- 品牌名过度（劳力士 / 兰博基尼 / 5 千一瓶的酒）
- 装逼模板（"我有的是钱"）

### 历史 / 武侠

额外禁用：
- 现代用语（"打卡""官宣"）
- 称呼错位（明朝人不能叫"先生"用法太晚）

### 末世 / 科幻

额外禁用：
- 设定堆砌开场
- 名词不解释直接用（"她拿出 P-37 多模态量子干涉仪" → 给读者一秒缓冲）

### 言情 / 女频

额外禁用：
- 男主滥用"宠溺"" 邪魅 一笑"
- 女主只剩"软糯"" 倔强"二选一

## 7. 自检流程（chapter-writer 写完后必跑）

```
1. 扫描全文，统计高频禁用词命中数。> 2 次的词列出。
2. 扫描禁用句式，逐条 grep。命中即标记。
3. 检查是否至少 1 项必备元素。
4. 统计对话占比。
5. 计算段落平均句数 / 单段最长字数。
6. 计算单句平均字数 / 最长句字数。
7. 出具自检报告，存到 audit/logs/chapter-NNNN.precheck.json
8. 如果发现严重命中（≥ 3 个高频词 / ≥ 2 条禁用句式），自动触发 anti-detect 模式重写一次
```

v1 由 LLM 自觉做 1-7 步，v2 由 CLI 工具强制。
