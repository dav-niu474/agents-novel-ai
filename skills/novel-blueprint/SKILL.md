# Novel Blueprint · 开书蓝图

把"我有个想法"或"我没想法"变成一份可被所有下游 skill 引用的**开书契约**。一旦 blueprint.md 状态变成 `approved`，它就是这本书的最高法令——后续 worldforge、character-atelier、outline-architect、chapter-writer 都要不与之冲突。

灵感工坊和开书定盘合并在这个 skill 里，因为它们是同一件事的两个状态：用户带脑洞来 → 直接定盘；用户没脑洞 → 先生成方向再定盘。

---

## 1. 何时使用 / 何时不要使用

✅ 使用：
- 用户带着 1-2 句话脑洞来（"想写穿越解析流"）
- 用户完全没思路（"给我几个开书方向"）
- 用户已经有部分设定但还没正式定盘（"主角是个程序员，但还没想金手指"）
- 用户想改 blueprint（"卖点改一下 / 重新定盘"）

❌ 不要使用：
- 用户已经在建世界 → `novel-worldforge`
- 用户已经在写大纲 → `novel-outline-architect`
- 用户问"起点最近什么火" → `novel-market-radar`（雷达完了再回 blueprint）
- blueprint 已 approved 且用户在写章节 → 不要重新定盘，让对应 skill 接手

---

## 2. 输入与输出契约

### 输入（必需）
- `novel.json`（由 novel-studio 已创建）

### 输入（可选）
- 用户的脑洞 / 想法 / 偏好
- `vault/inspirations/`（用户预先沉淀的灵感）
- `audit/trends/trend-*.md`（market-radar 输出的市场报告）
- 用户提供的参考作品（用于文风指纹）

### 输出
- `blueprint.md`（本 skill 主产物）
- 更新 `novel.json` 的若干字段（title / subtitle / genre / platform_target / audience / tags / core_pitch / target_chapters / target_chapter_words / agents.writer_voice / blueprint_status）

---

## 3. 工作流

### 工作流 A：灵感工坊（用户没想法）

触发：用户说"给我几个开书方向 / 没想法 / 帮我想一下"。

#### A.1 收集前提（最少 3 个问题）

只问最关键的 3 件事，不要把表单一次摆上：

1. **题材方向**：玄幻 / 仙侠 / 都市 / 历史 / 科幻 / 末世 / 游戏 / 无限流 / 言情 / 灵异 / 不确定（不确定也行）
2. **目标平台**：起点（男频付费）/ 番茄（免费 + 付费）/ 晋江（女频）/ 刺猬猫（二次元）/ 知乎盐选（短篇）/ 不确定
3. **个人偏好（一选其一）**：爽文 / 慢热铺垫 / 反套路 / 真情感线 / 都行

#### A.2 检索素材

如果工作目录有素材：

- 读 `vault/_index.json`，按用户题材 + 偏好做 tag 筛选
- 取 top-5 相关灵感卡 / 桥段
- 读最新的 `audit/trends/trend-*.md`（如果有）

#### A.3 生成 5-7 套差异化方向

每套方向必须**明确差异化轴**，不要给 5 套都是"穿越 + 修真 + 升级"的同质方向。差异化轴举例：

- 主角身份（程序员 / 医生 / 古代落魄书生 / 现代刑警 / 退役士兵）
- 金手指机制（解析 / 系统 / 模拟 / 复制 / 进化 / 召唤 / 时光）
- 故事节奏（慢热铺垫 / 上来就爽 / 反向打脸）
- 矛盾结构（个人复仇 / 家国大义 / 师徒情线 / 兄弟会战）
- 时空设定（架空古代 / 末法现代 / 星际未来 / 多元宇宙）

每套方向输出格式：

```markdown
### 方向 N：<一句话标题>

- **题材**：玄幻 + 末法
- **主角差异化**：现代研究生穿越成宗门末等弟子
- **金手指**：天工残卷，可解析任何接触过的功法 / 法宝 / 灵植
- **核心爽点**：从废柴到识破阴谋反杀，但不一招爆，靠"解析 → 找漏洞 → 反制"的智斗节奏
- **卖点**：解析流的代价机制（精神力反噬 / 失忆）让爽点不空泛
- **风险**：解析流近一两年比较多，需要在反派设计上做出差异化
- **3 章试读骨架**：
  - 第 1 章：被欺凌 → 山涧捡到玉简 → 解析杂草
  - 第 2 章：解析师兄功法找到漏洞
  - 第 3 章：反杀师兄，引起赵天霄注意
- **同类对标**：<某书> 的 <某点>
```

#### A.4 让用户挑一套

明确说"你想用方向 N，还是哪几条吸引你想合并出第 8 套？"

如果用户说"方向 3 + 方向 5 的金手指"，就重新合成第 8 套作为 candidate 给用户确认。

#### A.5 落定后进入工作流 B

把选定方向作为初始填充，进入 10 步定盘。

---

### 工作流 B：10 步定盘（用户已有方向）

触发：用户带着脑洞来 / 工作流 A 选定方向后。

⚠️ **核心原则：与用户协商，不替用户决定**。每一步给候选，让用户确认。

#### B.1：一句话定盘（pitch）

- 询问 / 提议：用 1-2 句话写出"这本书是什么书"
- 形式：`<主角身份> + <核心冲突 / 处境> + <金手指或差异化> + <最终目标 / 看点>`
- 例：末法时代穿越者，靠一本残卷解析天地间所有功法，从废柴成长为吞天魔帝

→ 写到 `blueprint.md` 第 1 节、`novel.json.core_pitch`

#### B.2：题材定位

- 主题材（必填）：玄幻 / 仙侠 / 都市 / 历史 / 科幻 / 末世 / 游戏 / 无限流 / 言情 / 灵异
- 副题材（可选）：末法 / 解析流 / 系统流 / 直播 / 校园 / 重生 / 穿越 / 萌宠 / 反派
- 平台（必选）：起点（首选）/ 番茄（同步）/ 晋江 / 刺猬猫 / 知乎盐选
- 受众：male-young-adult / male-middle / female-young-adult / female-middle / mixed

→ 写到第 2 节、`novel.json.genre / platform_target / audience / tags`

#### B.3：主角一句话画像

- 模板：`<现实身份>` + `<出身 / 起点>` + `<性格内核 1-2 个关键词>` + `<最深的渴望或恐惧>`
- 例：现代研究生穿越成宗门最末等弟子林烬，自卑、被欺，但有耐心和分析力，最深的渴望是"被看见"
- ⚠️ 不要让 AI 写浮夸的"天选之子 / 龙傲天"画像；让用户提供内核

→ 写到第 3 节

#### B.4：金手指一句话【中文网文核心】

- 模板：`<金手指名字>`：`<能做什么>`，`<触发条件>`，`<核心代价 / 限制>`
- 例：《天工残卷》：可解析任何接触过的功法 / 法宝 / 灵植 / 气息，输出"原理 + 缺陷 + 优化方向"，但需要消耗精神力，过度使用会反噬

⚠️ 必须包含**代价 / 限制**。没有代价的金手指 = 龙傲天 = 翻车。

⚠️ 不要在 blueprint 里写阶梯升级（那是 worldforge 的事），但要点出"会随境界变强"。

→ 写到第 4 节

#### B.5：卖点 / 钩子（前 30 章承诺）

写 4-5 个具体钩子，每个对应一个章节区间：

- 第 X 章前发生什么爽点（小目标）
- 第 X 章前发生什么转折（中目标）
- 第 30 章前到达什么高度（大目标）

例：
- 第 1 章：被欺凌的废柴林烬，意外获得残卷
- 第 5 章前：解析出第一门功法的缺陷，反杀挑事者
- 第 15 章前：识破宗门长老阴谋，绝境翻盘
- 第 30 章前：踏入宗门核心，残卷露出第二段封印

⚠️ 这些钩子是后续 outline-architect 写卷纲的硬约束。

→ 写到第 5 节

#### B.6：反 AI 味要求

询问 / 提议：

- 高频禁用词（让 AI 文味重的词，例如"眉头一皱"、"事情并不简单"、"不可思议"、"震撼"）
- 禁用句式（"四字成语堆砌"、"过度心理独白"、"宿命感开场"）
- 必备元素（具体场景细节 / 五感描写 / 不规则的小动作 / 对话占比）

→ 写到第 6 节

#### B.7：文风指纹（可选）

询问：是否要导入参考作者 / 文本？

- 是 → 用户提供参考文本路径或贴上几段；建议用户去 vault 沉淀（让 asset-vault 接手提取风格指纹）
- 否 → 默认通用网文风（动作干脆、对话占比 30-45%、段落 2-4 句）

→ 写到第 7 节

#### B.8：排除项

明确不写什么。这比"写什么"更重要——避免日后写偏。

例：
- 不写：种马、龙傲天到底、纯打脸爽文
- 写：废柴翻身、智斗多于硬刚、师徒情线

→ 写到第 8 节

#### B.9：章字数 / 节奏

- 章字数（默认 3500，起点 / 番茄上推荐 2500-4000）
- 对话占比目标（默认 30-45%）
- 段落节奏（手机阅读：2-4 句 / 段）

→ 写到第 9 节、`novel.json.target_chapter_words`

#### B.10：长期意图

- 计划多少卷 / 多少章（estimate，可后续调）
- 整体节奏（前期铺垫 X 章 → 中期 Y 章 → 后期 Z 章）
- 结局倾向（开放式 / 圆满 / 悲壮 / BE / HE / 反转）

→ 写到第 10 节、`novel.json.target_chapters`

---

### 工作流 C：blueprint 修订

触发：blueprint 已 approved，用户说"金手指改一下 / 卖点改一下 / 排除项加一条"。

步骤：

1. **强警告**：blueprint 已 approved，修改会影响所有下游资产（world / characters / outline）。询问是否确认。
2. 用户确认后，**针对性更新**对应小节，version + 1。
3. 更新 `updated_at`。
4. **告诉用户哪些下游资产可能受影响**：

| 改动 | 受影响的下游 |
|------|-------------|
| 主角画像 | characters/protagonist-*.md |
| 金手指 | world/cheat-system.md（必须重写）+ outline/chapters/*（爽点节拍可能错乱） |
| 卖点 / 钩子 | outline/master.md + outline/volumes/volume-01.md |
| 反 AI 味 / 文风 | chapter-writer 后续章节自动遵守新约束 |
| 题材 / 平台 | 整本基本要重做 |

5. 让用户决定是否触发对应下游 skill 重做。

## 5. 关键规则

### R1：协商，不替决定

每一步给候选，让用户挑 / 改。不要 AI 一次性把 10 步都填好然后让用户"看看对不对"——那样用户只会"嗯嗯好"，得到 GPT 风格的同质开书。

### R2：金手指必须有代价

第 4 步的金手指描述如果没有代价 / 限制 / 触发条件，**强制要求用户补**。

不接受"主角自带逆天天赋，越战越强"这种没有代价的金手指。

### R3：钩子要具体到章

第 5 步的卖点钩子必须挂到具体章节（不晚于 30 章），不能写"未来某天"。

### R4：approved 后修改要明示影响范围

工作流 C 第 4 步必须做。

### R5：不直接写 world / characters / outline

blueprint 只写 blueprint.md + 更新 novel.json 字段。其他都不动。

### R6：每写完一个版本前 ask once

在用户说"开始定盘"后，定到第 10 步前先 echo 一遍 10 个字段的填充情况，让用户确认 status: approved。

## 7. 错误处理

| 错误场景 | 处理方式 |
|---------|---------|
| `novel.json` 不存在 | 回到 `novel-studio` 让其先初始化 |
| 用户跳着填，第 4 步问起第 8 步 | 允许，不强制顺序，但提醒"如果跳过前 3 步金手指可能定不准" |
| 用户给了大段无结构脑洞 | 自动抽取成 10 个字段的初稿，让用户校对 |
| 用户希望"AI 全自动写完 blueprint" | 警告这违反 R1，但允许在用户明确要求时执行；执行后强制让用户逐节校对 |
| 用户改主题材 | 警告这意味着 blueprint 几乎要重写 |

用户：玄幻，起点，反套路。

blueprint：[扫 vault/inspirations/，读 audit/trends/]
         给你 6 套差异化方向：
         
         ### 方向 1：废柴的"反向解析"
         主角能解析功法但只能解析 < 自己境界的，强制反套路：早期被压制
         金手指：以小博大，靠对方的"破绽链"反杀

         天才主角，但每次突破都要付出"等量爱人记忆"
         反套路点：变强即变孤独
         
         ### 方向 3：神选之子开局即跌落
         传说中的圣者转世，但开局发现是被冒名顶替
         反套路：拒绝接受身份，自己重新挣身份
         
         ### 方向 4：装弱的强者
         穿越前是顶级修士，穿越后必须装废柴 200 章
         反套路：爽点是"装"的精彩
         
         ### 方向 5：金手指会消失
         第 1 章给金手指，告诉读者"这个能力会在第 100 章消失"
         反套路：从不靠金手指赢
         
         ### 方向 6：反派穿越
         主角是末日反派 boss，穿越成正派师弟
         反套路：自己是反派但偏要做正派
         
         你想哪个？或者哪几条想合并？

用户：方向 1 + 方向 5 的金手指会消失这一点。

blueprint：[合成方向 7]
         合成方向 7：
         
         ### 方向 7：废柴的反向解析 + 金手指会消失
         主角金手指：天工残卷，可解析所有 < 自己境界的功法 / 法宝
         反向规则：境界越高，能解析的范围反而变小（高境界后只能解析旧物）
         消失承诺：第 200 章左右，残卷会"任务完成"消失，主角必须靠自己活下去
         反套路点：最强的章节是金手指消失前的"用尽"，和消失后的"自立"
         
         接受这个方向、还是再调？
         
用户：接受，开始正式定盘。

→ 进入工作流 B 10 步定盘
