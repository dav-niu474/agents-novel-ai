  ===== 中文网文常见 7 大金手指流派 =====
  选一个最贴近的作为基底，然后做差异化改造：
  
  1. 解析流（analyzer）：能"看穿 / 解构"功法 / 法宝 / 灵物
     - 代表：识破漏洞、找弱点、提炼原理
     - 代价候选：精神力、反噬、记忆
  
  2. 系统流（system）：脑海里有"系统"，发布任务并奖励
     - 代表：任务流、签到流、积分商城
     - 代价候选：违约惩罚、有限选择、隐性目的
  
  3. 模拟流（simulator）：可"预演"未来 / 路线 / 分支
     - 代表：人生模拟、剧情推演、推演功法
     - 代价候选：模拟次数、消耗寿命、信息差
  
  4. 召唤流（summoner）：召唤分身 / 灵兽 / 历史人物
     - 代表：万界召唤、武魂召唤、契约兽
     - 代价候选：契约代价、召唤冷却、忠诚危机
  
  5. 复制流（copier）：能复制 / 学习 / 镜像他人能力
     - 代表：偷天换日、众生武库、武学无敌
     - 代价候选：能力上限、记忆碎片、副作用
  
  6. 进化流（evolver）：自身或某物随积累而进化
     - 代表：吞噬进化、血脉觉醒、装备升级
     - 代价候选：进化方向锁定、副作用、阶段瓶颈
  
  7. 时光流（time）：时间相关 - 倒流 / 暂停 / 加速 / 重生
     - 代表：重生、时间停止、回溯
     - 代价候选：寿命消耗、悖论、回溯次数限制
  
  ⚠️ 也可组合（例：解析 + 复制 = "解析后能改造")，但本卡只填一个主流派。
